# 🛒 nopCommerce - Testes Automatizados com Cypress

Projeto de automação de testes end-to-end (E2E) para o site de e-commerce de demonstração [nopCommerce](https://demo.nopcommerce.com/), utilizando **Cypress** e **JavaScript**.

O objetivo é validar os principais fluxos de uma loja virtual, aplicando boas práticas de automação, organização de código e testes confiáveis e de fácil manutenção.

## 🎯 Objetivos

- Automatizar os fluxos críticos de um e-commerce
- Praticar e demonstrar boas práticas com Cypress
- Garantir testes independentes, legíveis e reutilizáveis
- Servir como projeto de portfólio em QA/automação de testes

## ✅ Funcionalidades cobertas

- Cadastro de usuário
- Login e logout
- Busca de produtos
- Navegação por categorias
- Adição e remoção de produtos no carrinho
- Lista de desejos (wishlist)
- Comparação de produtos
- Fluxo de checkout
- Validações de formulários e mensagens de erro

## 🛠️ Tecnologias

- [Cypress](https://www.cypress.io/)
- JavaScript
- Node.js
- Page Object Model / Custom Commands
- Mochawesome (relatórios) *(opcional)*
- GitHub Actions (CI) *(opcional)*
